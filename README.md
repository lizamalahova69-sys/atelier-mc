# Ателье M&C — сайт

Статический сайт: HTML + CSS + немного JS. **Сборка не нужна**, Node/npm не нужен.

```
index.html    главная страница
services.html услуги и цены, открывается по адресу /services
gallery.html  галерея работ, открывается по адресу /gallery
styles.css    оформление обеих страниц
app.js        меню, галерея, ленивые виджеты Яндекса
photos/       все фотографии сайта
favicon.svg   иконка вкладки
og.svg        картинка для превью в мессенджерах
vercel.json   чтобы адрес был /gallery, а не /gallery.html
robots.txt    сюда же sitemap
sitemap.xml
```

Шапка, подвал и окно «Написать нам» скопированы во всех трёх файлах — сборки нет,
поэтому общий кусок вынести некуда. Если правите меню, телефон или ссылки на мессенджеры —
меняйте **во всех трёх**.

## Что нужно заполнить

### 0. Цены на странице услуг — САМОЕ СРОЧНОЕ

В `services.html` стоят **не ваши цены**, а средние по ателье Краснодара — взяты с profi.ru
и masterminutka.ru, чтобы страница не была пустой. Их нужно заменить на свои.

Ищите в файле блоки `<ul class="price-list">`, формат строки:

```html
<li><span>Подшив брюк, юбки, джинсов</span><b>400–1 500 ₽</b></li>
```

Меняется только то, что внутри `<span>` и `<b>`. Где написано «считаем по эскизу»
или «оценим при осмотре» — цифр у меня не было вообще, впишите свои.

Когда цены станут вашими, уберите из `services.html` абзац `<p class="notice">`
со словами «Цены ориентировочные и пока уточняются».

### 1. График работы (обязательно)

В `index.html` найдите комментарий `<!-- TODO: подставьте точный график -->` в секции контактов.
Сейчас там честная заглушка: «Работаем до 19:00, точный график уточняйте по телефону» —
потому что точных часов у меня не было и я не стал их выдумывать.

Замените на реальный график, например:

```html
<dd>Пн–Пт 09:00–19:00<br>Сб 10:00–16:00<br>Вс — выходной</dd>
```

Заодно добавьте график в блок разметки для поисковиков — в `<script type="application/ld+json">`
внизу `index.html`, после строки с `"geo"`:

```json
"openingHoursSpecification": [
  { "@type": "OpeningHoursSpecification",
    "dayOfWeek": ["Monday","Tuesday","Wednesday","Thursday","Friday"],
    "opens": "09:00", "closes": "19:00" },
  { "@type": "OpeningHoursSpecification",
    "dayOfWeek": "Saturday", "opens": "10:00", "closes": "16:00" }
],
```

### 2. Фотографии

Фотографии со стока Unsplash (бесплатная лицензия, в том числе для коммерческого
использования) лежат в папке `photos/` прямо в репозитории.

**Важно: не подключайте картинки ссылками на зарубежные сайты.** Изначально они грузились
напрямую с `images.unsplash.com`, и на мобильных операторах в России этот адрес
не открывается — на телефонах сайт был вообще без картинок. Все фото должны лежать
в `photos/` и отдаваться с того же домена, что и сайт.

**Но свои фото продают гораздо лучше.** На них видно вашу работу, а не абстрактное ателье.

Где лежат картинки:

| Место | Где в коде |
|---|---|
| Фон первого экрана | `index.html`, блок `<div class="hero-media">` |
| 8 карточек услуг | `index.html`, блок `<div class="services-grid">`, тег `<img class="s-img">` |
| Фото в разделе «Почему к нам приходят» | `index.html`, блок `<div class="split-media">` |
| 6 фото витрины на главной | `index.html`, блок `<div class="gallery teaser">` |
| 15 фото полной галереи | `gallery.html`, блок `<div class="gallery">` |
| Фон широкой полосы с цитатой | `styles.css`, правило `.banner`, свойство `background-image` |

Как заменить: положите файлы в папку `photos/` рядом с `index.html` и поменяйте `src` и `alt`:

```html
<button class="shot reveal" type="button"
        data-full="/photos/svadebnoe-platie-big.jpg">
  <img src="/photos/svadebnoe-platie.jpg"
       alt="Подгонка свадебного платья по фигуре"
       loading="lazy" width="800" height="600">
</button>
```

- `src` — картинка в сетке (хватит ширины ~1100 px).
- `data-full` — крупная версия, она открывается по клику. Можно не указывать —
  тогда откроется та же, что в сетке.
- `alt` — короткое описание того, что на фото. Его читают поисковики и незрячие посетители.

Фото сожмите до ширины ~1600 px (например, на squoosh.app), иначе страница будет грузиться
медленно. Плитки в галерее бывают разных размеров — классы `big`, `wide`, `tall` у кнопки
`.shot`. Если поменяете набор фото, следите, чтобы сумма занимаемых клеток была кратна 4,
иначе в мозаике появится дырка.

## Публикация на Vercel

Сайт статический, поэтому команда сборки не нужна.

**Если проект уже подключён к GitHub:** замените в репозитории всё содержимое на файлы из
этой папки, удалите `package.json`, `vite.config.js` и папку `src`, закоммитьте и запушьте.
В настройках проекта на Vercel: Framework Preset → **Other**, Build Command — пусто,
Output Directory — пусто (корень).

**Через веб-интерфейс:** vercel.com → проект → Deployments → можно перетащить папку.

**Проверить локально** (Python уже стоит на компьютере) — из этой папки:

```bash
python -m http.server 8123
```

Затем откройте http://localhost:8123

## Что стоит сделать дальше

- Заменить сток на свои фото (пункт 2) — самое заметное улучшение.
- Добавить в галерею пары «до / после» — для ателье это самый убедительный формат.
- Добавить 3–4 живых отзыва текстом прямо на страницу: виджет Яндекса грузится
  секунду-другую и его содержимое поисковики не индексируют.
- Указать ориентиры «как пройти»: этаж, вход, что рядом.
- Если появятся типовые цены («подшив брюк — от N ₽») — добавить их в карточки услуг.
  Люди ищут цену и уходят с сайтов, где её нет.
